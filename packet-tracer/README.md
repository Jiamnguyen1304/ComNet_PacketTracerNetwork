# Artifact hỗ trợ Packet Tracer

File nhị phân chuẩn là `../topology.pkt` ở thư mục gốc repository, được lưu bằng
Cisco Packet Tracer 9.0.1. Thư mục này chỉ giữ running-config và website source.

Chỉ một thành viên được giữ quyền sửa file này tại một thời điểm. Sau mỗi thay
đổi cấu hình, export running-config liên quan vào `configs/`.

Các file trong thư mục này gồm:

- `../topology.pkt`: mô hình Packet Tracer hoàn chỉnh đang dùng.
- `configs/`: running-config của 4 router và 5 switch.
- `web/index.html`: nội dung chép vào WEB-SRV.
